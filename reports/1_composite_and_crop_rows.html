How the three runs add up to one scored set

Pooled means one roster, one matcher pass and one F1 — not the average of three, which would weight a 107-tile corpus like a 377-tile one.

26 tiles are on two rosters, and they are counted once. The edge-cases run reads the four Toppenish output files as well as its own, and 26 Toppenish tiles sit on its roster — the same request answered by the same response. Concatenating the runs would give 692 tile items over a 666-tile union. Each duplicate is taken from the first run that carries it and the dropped copy is checked against the one kept, so a disagreement would raise rather than be averaged away.
